AI 工具部署助手使用教程

这是第三方部署工具。软件不会提供模型账号、API Key、代理或地区限制绕过。

1. 激活客户版

打开软件，输入管理员交付的 ADA- 兑换码。每个兑换码绑定一台设备，换机需要管理员在后台重置。

2. 安装工具

选择 Claude Code、OpenClaw 或 Hermes Agent，先查看详情，再点击安装。客户端会验证签名清单、文件大小和 SHA-256。

3. 初始化

Claude Code 可选择项目目录并预览配置差异；OpenClaw 和 Hermes 安装后使用“打开终端”运行官方初始化向导。

4. 诊断与修复

“诊断”会检查工具路径和官方 doctor 命令。“重新安装 / 修复”会重新验证并安装当前签名版本。

5. 更新助手

点击“检查助手更新”。更新包使用独立签名验证，下载完成后应用自动重启。
